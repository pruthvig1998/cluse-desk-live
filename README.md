# Cluse desk, live

A public, read-only view of the Cluse paper-trading bot: a snapshot of the book, the signals and the bots every 5 minutes in the session.

- Live desk: https://pruthvig1998.github.io/cluse-desk-live/
- 3D diagram of the system: https://pruthvig1998.github.io/cluse-desk-live/3d/

This repo holds only the page and its data (the `data` branch). It is published automatically by the bot; nothing here is edited by hand.

Paper trading only - educational, not financial advice. No real orders, ever.
